# Mean Process Specification

Six types of mean processes are of interest:

- **Constant**: $\pi_{t+1} = SPF_t + u_{t+1}$
- **ARX(1,0)**: $\pi_{t+1} = c + \rho_1 \pi_t + u_{t+1}$
- **ARX(1,1)**: $\pi_{t+1} = c + \rho_1 \pi_t + \phi_1 SPF_t + u_{t+1}$
- **ARX(2,0)**: $\pi_{t+1} = c + \rho_1 \pi_t + \rho_2 \pi_{t-1} + u_{t+1}$
- **ARX(2,1)**: $\pi_{t+1} = c + \rho_1 \pi_t + \rho_2 \pi_{t-1} + \phi_1 SPF_t + u_{t+1}$
- **ARX(2,2)**: $\pi_{t+1} = c + \rho_1 \pi_t + \rho_2 \pi_{t-1} + \phi_1 SPF_t + \phi_2 SPF_{t-1} + u_{t+1}$

where $u_{t+1}$ is the residual term. In ARX($p$,$q$), $p$ is the number of
inflation lags and $q$ the number of SPF terms. ARX(1,0) and ARX(2,0) are pure
autoregressions without the professional forecast; they are included for
reference, to show what the SPF terms add to the inflation lags.


<!-- [^1]: In the GARCH family estimation exercise, we found that  ARX(2,2) is always dominated by other three specifications. Thus, we stop estimating ARX(2,2) in BEGE estimation to saving computational resources. -->

## OLS Results

HAC(12) denotes heteroskedasticity- and autocorrelation-consistent standard errors with 12 lags. The reported OLS AIC and BIC use the estimation package's count of fitted mean coefficients; the anchored Constant calculation counts one residual-variance parameter. Unlike the volatility-model criteria, the ARX OLS criteria omit the variance parameter. For comparisons using a common count, add $2$ to each ARX OLS AIC and $\ln T$ to its BIC. The displayed values retain the original convention.

The OLS results below are generated by `mean_process_ols.py`.
